# AETHER — Creative Direction & Production House

A 1-of-1 cinematic dark luxury website for AETHER, a creative direction and production house crafting films, campaigns, and brand identities for clients who shape culture—not chase it.

## Tech Stack
- HTML5 (semantic, accessible)
- CSS3 (custom properties, grid, flexbox, clamp, backdrop-filter)
- Vanilla JavaScript (Intersection Observer, no dependencies)

## Design System
- **Background:** #070707 (near-black)
- **Text:** #f0f0f0 (off-white)
- **Accent:** #bcbcb5 (metal)
- **Font:** Inter (Google Fonts)
- **Grid:** 12-column, 1120px max container
- **Sections:** 9 (Threshold → Footer)

## Structure
- `index.html` — 9 sections, semantic HTML5
- `styles.css` — dark luxury tokens, components, responsive
- `main.js` — scroll animations, mobile menu, form, parallax

## Features
- Responsive (desktop, tablet, mobile)
- Scroll animations (Intersection Observer)
- Mobile menu (full-screen overlay)
- Hero spotlight parallax
- Contact form with inline success state
- Accessible (focus states, reduced motion, ARIA labels)
- SEO-ready (meta description, semantic HTML)

Open `index.html` in any modern browser.
